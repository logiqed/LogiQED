# DePIN Integrations

## Idea

Connect LogiQED events to DePIN networks for driver income.

## Problem

Drivers collect useful data during trips but have no way to monetize it.

## How It Works

1. Driver device captures road data, telemetry, connectivity, weather.
2. Data is signed and sent to LogiQED ingest.
3. LogiQED routes anonymized data to DePIN partners.
4. Partner verifies contribution.
5. Driver earns tokens or stablecoins.

## Example Integrations

- Hivemapper: road mapping, AI dashcam
- DIMO: vehicle telemetry via OBD-II
- WindChain: road wind conditions
- SignalMap: cellular coverage data

## Technical Dependencies

- Signed Event Stream
- AI-friendly API
- Webhooks
- Device identity

## Why Later

Requires stable DePIN partnerships and token incentives.

Core evidence layer must be production first.
