# Scientific Sensors

## Idea

Trucks as mobile science labs for citizen science.

## Problem

Researchers lack dense, real-world data across large areas.

## How It Works

1. Sensors installed on trucks: air quality, weather, radiation.
2. Sensors sign data locally.
3. Data enters LogiQED Evidence Graph.
4. Researchers query verified datasets.
5. Drivers earn compensation or reputation.

## Example Sensors

- PM2.5, PM10 air quality
- Temperature, humidity, pressure
- Radiation dosimeter
- Road surface temperature

## Technical Dependencies

- Device attestation
- Sensor calibration chain
- Evidence Assurance
- Data licensing layer

## Why Later

Sensor calibration and data quality are hard.

Start with core freight evidence.
