# MeshShield

## Idea

Truck mesh network for theft prevention.

## Problem

Parking lots and grey zones have no collective security.

## How It Works

1. Trucks run sensors: vibration, light, door state.
2. Suspicious event triggers local alert.
3. Alert broadcasts to nearby trucks via mesh radio.
4. Fleet operator receives signed event.
5. Evidence stored for insurance and police.

## Technical Dependencies

- Local mesh networking
- IoT sensors
- Signed events
- Low-latency alerting

## Why Later

Requires hardware deployment and network density.

Start with signed IoT seals and GPS events.
