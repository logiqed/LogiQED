# Contributing to LogiQED

Thank you for your interest in LogiQED.

## How to Contribute

At this stage, LogiQED is a closed blueprint. We welcome feedback, questions, and discussions from potential partners and contributors.

## Issues

Use GitHub Issues for:

- Reporting documentation errors
- Asking questions about the architecture
- Suggesting improvements to evidence layer, trust model, or claims

## Pull Requests

Pull requests are currently accepted only from invited contributors.

If you have a proposal, open an issue first. We will invite you if the change fits the roadmap.

## Code of Conduct

Be direct. Be technical. Be respectful.

No hype. No spam. No token talk.

## Contact

Reach out through GitHub or the official @LogiQED account.
