# Pilot Plan

## Goal

Prove that LogiQED produces trustworthy evidence and settles a real commercial dispute.

## Scope

3–5 trucks. 2–4 weeks of real trips. EU lane.

## Data Sources

- Smartphone GPS
- Temperature sensor for cold-chain
- Traffic API
- Weather API
- Warehouse geofence events

## Claims to Prove

1. Detention / Warehouse Waiting Claim
   - Appointment, geofence entry, dock assignment, loading start, exit.
   - Warehouse attributable waiting.

2. Cargo Condition Claim
   - Committed measurements from E4 sources stayed within contract.

## Success Criteria

- Real trucks produce signed events.
- SLA engine resolves exceptions automatically.
- Two claims verified end-to-end.
- At least one real commercial dispute or SLA exception is settled using the Evidence Package instead of the legacy manual process.

Before: 2 days, 8 emails, 3 PDFs, 2 phone calls, manual investigation.

After: Evidence Package, automatic verification, 12 minutes.

## Deliverables

- Signed Event Stream
- Evidence Graph for each trip
- Evidence Packages for Detention and Cargo Condition
- Benchmarks for proof generation
- Pilot report with case study

## Next Step

Find pilot partner: shipper, 3PL, insurer or freight forwarder who makes penalty or payout decisions.
