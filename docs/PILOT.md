# LogiQED Pilot Plan

## Goal

Prove the Evidence OS on real trucks.

## Scope

3–5 trucks. 2–4 weeks of real trips. EU lane.

## Data Sources

- Smartphone GPS
- Temperature sensor for cold-chain
- Traffic API
- Weather API
- Warehouse geofence events

## Claims to Prove

1. SLA Exception Claim
   - Late arrival explained by traffic or warehouse queue.
   - Chargeable delay: 0.

2. Cargo Condition Claim
   - Temperature stayed within contract during custody.
   - Proof: VALID.

## Success Criteria

- Real trucks produce signed events.
- SLA engine resolves exceptions automatically.
- Two claims verified end-to-end.
- Evidence Package exported for external review.
- At least one partner confirms the package is useful for settlement or insurance.

## Deliverables

- Signed Event Stream
- Evidence Graph for each trip
- Evidence Packages for SLA Exception and Cargo Condition
- Benchmarks for proof generation
- Pilot report

## Next Step

Find pilot partners: carrier, warehouse operator, or insurer with real freight.
